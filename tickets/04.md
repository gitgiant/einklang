# [v1] Renderer abstraction: WebGPU + WebGL2, WGSL→GLSL via naga

Backend interface (buffers, pipelines, passes, post-FX chain). WGSL sources are converted to GLSL ES 3.0 at build time with naga; CI compiles both. Feature-detect WebGPU and fall back to WebGL2. Hash display = integer scene state + uniforms.
