# [v1] [done] Instrument mode + display-rate interpolation

Live line-in leader with a 1–2 tick render delay on all hosts, leader included. Displays at 90/120/144 Hz interpolate between 60 Hz ticks.

Blocked by: #3, #4

Done 2026-11-26: live mode carries `delay` (mic / line-in = INSTRUMENT_DELAY 2, tab/app capture = LIVE_DELAY 6); late live frames rewind sims. Scenes take `state(f, F, sub)`; radial, tunnel and transition progress interpolate at f + sub/256 (draw only, the hash uses sub = 0), scope and flow show their latest tick. Applies at every refresh rate; `?interp=0` turns it off.
