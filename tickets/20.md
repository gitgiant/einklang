# [lab] Graph runtime + piece API

The node-graph runtime that replaces the render pipeline. It has typed ports (tex, mask, field, particles, geo, camera, palette, signal, trigger, spectrum, wave), `lab/scenes/<id>.json` (nodes, edges, bindings, author, parent, status), topological evaluation each frame, a pooled render-target set, modulator bindings on numeric params, and a hash over graph inputs (scene id + version, tick, features, inputs, resolved int params, plus the state of `synced` nodes). `lab/api` provides `definePiece`, and Vite globs `lab/pieces/**`. Full spec: docs/prd-lab.md.
