# [lab] Sprites, text, style packs, AI sprite generation

Sprite/atlas import (PNG + Aseprite JSON, GIF, .vox slices), a sprite node (beat-timed frames) and a sprite emitter, a font baker (bitmap + MSDF), a `text` param type, `.lrc` lyrics next to tracks, and style packs (palette + FX chain + fonts). AI sprites are code-drawn by default. `einklang-lab sprite gen` calls an image API (Gemini image / gpt-image) only when the brief sets `imagegen: N`, with a monthly cap in host config. Output is downscaled, quantized to the palette, background-removed and packed, then vendored with the model and prompt. Full spec: docs/prd-lab.md.
