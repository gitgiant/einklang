# [v1] Gamepad relay + multiplayer FX layers

Gamepad API on any host, sampled per tick and relayed. Each pad gets a color and its own layer. Mapping: face buttons = shockwave/strobe/kaleido/invert, sticks = FX center/rotation-zoom, L2/R2 = trails/bloom, L1/R1 = scene, D-pad = palette/view; plus hit, blackout, freeze, drift toggle.
