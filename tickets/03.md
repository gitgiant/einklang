# [v1] Protocol v2: tick-stamped events, server-authoritative state, 8-bar log

Generic event stream {tick, source, type, payload}, applied at effectiveTick = now + inputDelay. The server decides scene/sceneSwitchTick, view overrides, particle N, clock master and mode. It keeps a ring of features and events since the last reseed (8 bars at minimum) and sends it to joiners.
