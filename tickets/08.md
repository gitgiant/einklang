# [v1] [done] Fixed-point flow-field sim + TF fallback + reseed/fast-forward + N benchmark

Curl-noise flow field in i32 fixed point, run as WGSL compute; the WebGL2 path uses transform feedback with integer GLSL. Reseed on scene enter and every 8 bars. Joiners fast-forward through the log at ~50 steps per frame. Hosts report a benchmark on join; the server sets N to the weakest host's capability and renegotiates at reseed; extra closed-form dust on strong GPUs. Test: bit-identical hash across both backends.
