- **2026-11-26 · waveform stream (#7).** Binary frames optionally carry a WAVE_BYTES (512 L/R int8) block per tick: file mode appends all of it after the features (worker computes it; ~60 KB/s of audio), live leader taps L/R with a splitter + analysers. `fileSource`/`mapSource` expose it as `wave(t)`; the scope uses it and auto-gains into its circle (scope golden hash updated deliberately).
- **2026-11-25 · gamepads (#10).** `src/web/pads.ts` polls each frame and sends `pad` state on change; edge buttons map to scene/palette/view/hit/freeze/tap. The server assigns slots (8, freed on leave with a `gone` event). It also owns palette/freeze (absolute values) and tap tempo (sets the grid if no MIDI clock). EventLog's CC index became a generic state-key index (`stateKey`, `latest`, `history`); the server keeps `latest` per key and carries it across epochs. `core/fx.ts` `fxAt(log, tick)` gives rings/cursors/strobe/kaleido/invert/blackout/trails/bloom/drift; the post shader draws them (uniform slot is now 512 B). Freeze evaluates the scene at the frozen tick. Verified in e2e with a socket playing a pad; no real pad tested.
- **2026-11-25 · playlist + transport.** **files** / **folder** load a local playlist on that host (`src/web/player.ts`); decode on the main thread, analysis in `analyze.worker.ts`, the next track pre-analyzed. Room state gained `playlist {owner,names,index}`, and file mode gained `name` and `paused`. pause/resume/seek are new epochs (`start` shifted, `paused` = frozen frame); `track` requests are relayed to the owner, who also auto-advances. The bottom bar has prev/play/next, progress and seek. The HUD is hidden (its text lives in the debug panel). Verified with real mp3s (Pioneer demo tracks) in e2e.
